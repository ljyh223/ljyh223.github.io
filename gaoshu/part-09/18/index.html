    第 18 章 向量组 #

    第九篇 · 线性代数

    官方要求第三部分八（三）。A｜线性相关性判别；B｜线性组合、表示、相关与无关的定义、极大线性无关组与秩；C｜nnn 维向量概念。

    先看懂题，再下笔 #

    把向量当成几列已有数据。“能否表示”问的是能不能用已知列拼出目标列；“线性相关”问的是能不能用一组不全为零的系数拼出零列。两种问题都可以列方程组。题目让找一组极大线性无关组时，消元找列号，再回原题抄出这些列。

    18.1 nnn 维向量 #

    实 nnn 维列向量 v=(v1,…,vn)T\mathbf v=(v_1,\ldots,v_n)^Tv=(v1​,…,vn​)T 是有顺序的 nnn 个实数。相等需每个分量相等，加法与数乘逐分量进行。只要分量数相同就能组成向量组，可用矩阵把每个向量作为一列摆放。

    18.2 向量的线性组合与线性表示 #

    c1v1+⋯+cmvmc_1\mathbf v_1+\cdots+c_m\mathbf v_mc1​v1​+⋯+cm​vm​ 是向量的线性组合。b\mathbf bb 可由这组向量线性表示，意思是存在一组系数使该组合等于 b\mathbf bb。把列摆成 A=[v1 ⋯ vm]A=[\mathbf v_1\ \cdots\ \mathbf v_m]A=[v1​ ⋯ vm​]，即求 Ac=bA\mathbf c=\mathbf bAc=b。若有解则可表示，系数的唯一性由齐次方程决定。

    18.3 向量组的线性相关性 #

    若存在一组不全为零的系数使 ∑civi=0\sum c_i\mathbf v_i=\mathbf0∑ci​vi​=0，向量组线性相关；只有全零系数解时线性无关。从非零 cjc_jcj​ 可解出 vj=−∑i≠j(ci/cj)vi\mathbf v_j=-\sum_{i\ne j}(c_i/c_j)\mathbf v_ivj​=−∑i=j​(ci​/cj​)vi​，所以相关组中至少一个向量可由其余向量表示。包含零向量的组总相关。

    18.4 线性相关与无关的判定 #

    设 AAA 有 mmm 个列向量。若 r(A)=mr(A)=mr(A)=m，每列均有主元，零组合只能全零，线性无关；若 r(A)<mr(A)<mr(A)<m，有自由变量，线性相关。nnn 维空间中超过 nnn 个向量必相关；恰有 nnn 个时也可用 det⁡A≠0\det A\ne0detA=0 判无关。

    18.5 极大线性无关组 #

    极大线性无关组是从原组中选出的无关子组，加入任何漏选向量都会变相关。设 w\mathbf ww 为漏选向量，合在一起相关而子组无关，故 w\mathbf ww 对应系数不可能为零，从而 w\mathbf ww 可由子组表示。将原列矩阵行消元，读取主元列的列号，再回到原矩阵取相应列。行变换保持列间依赖关系，但会改变列向量本身。

    18.6 向量组的秩 #

    向量组的秩等于任一极大线性无关组包含的向量数，也是列矩阵的秩。投影到阶梯矩阵后，主元列能张成全部列，且各自独立，因此能用同一个消元同时求秩和一组极大无关组。

    典型例题 #

    基础例题。 判断 a=(1,2)T,b=(2,4)T\mathbf a=(1,2)^T,\mathbf b=(2,4)^Ta=(1,2)T,b=(2,4)T 是否线性相关。直接有 b=2a\mathbf b=2\mathbf ab=2a，因此 2a−b=02\mathbf a-\mathbf b=\mathbf02a−b=0 是非零系数组合，相关，秩为 111。

    进阶例题。 对 a=(1,1,0)T,b=(0,1,1)T,c=(2,3,1)T\mathbf a=(1,1,0)^T,\mathbf b=(0,1,1)^T,\mathbf c=(2,3,1)^Ta=(1,1,0)T,b=(0,1,1)T,c=(2,3,1)T，求极大无关组并表示 c\mathbf cc。前两列构成的方程 sa+tb=0s\mathbf a+t\mathbf b=0sa+tb=0 由首末行得 s=t=0s=t=0s=t=0，故无关。解 sa+tb=cs\mathbf a+t\mathbf b=\mathbf csa+tb=c，首末行给 s=2,t=1s=2,t=1s=2,t=1，中间行 2+1=32+1=32+1=3 验证成立，故极大无关组可取 {a,b}\{\mathbf a,\mathbf b\}{a,b}，秩为 222。

    解题策略与易错点 #

    用列表示可把相关性、秩和线性表示统一在同一张矩阵上。极大无关组可以有多个，找到一组后要检验它能张成原组。行消元后用主元列号回原矩阵取列。

    巩固练习 #

    1. 含 0\mathbf00 的三向量组能否线性无关？
    2. 求 (1,0,1)T,(0,1,1)T,(2,3,k)T(1,0,1)^T,(0,1,1)^T,(2,3,k)^T(1,0,1)T,(0,1,1)T,(2,3,k)T 相关时的 kkk。
    3. (1,1,2)T(1,1,2)^T(1,1,2)T 能否由 (1,0,0)T,(0,1,0)T(1,0,0)^T,(0,1,0)^T(1,0,0)T,(0,1,0)T 线性表示？

    答案解析 #

    1. 取零向量的系数为 111，其余为 000，得到非零系数的零组合，所以相关。
    2. 前两向量无关。若第三个可表示，由前两坐标得系数 2,32,32,3，最后坐标要求 k=2+3=5k=2+3=5k=2+3=5；该值时确实相关。
    3. 前两向量任意组合最后分量都是 000，目标为 222，故不能表示。
