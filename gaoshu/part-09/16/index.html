    第 16 章 行列式 #

    第九篇 · 线性代数

    官方要求第三部分八（一）。A｜行列式性质、按行列展开和相应计算；C｜行列式概念。特殊结构用于练习性质。

    先看懂题，再下笔 #

    先区分两个对象：矩阵是整张数字表，行列式是这张方阵算出来的一个数。看见某行只有一个非零数，就沿那一行展开；若可以用一行减另一行的倍数制造更多零，先消元。换行要记负号，直接倍加没有额外系数。

    16.1 二阶、三阶行列式 #

    行列式把方阵映射为一个数。二阶为 ∣abcd∣=ad−bc\begin{vmatrix}a&b\\c&d\end{vmatrix}=ad-bc​ac​bd​​=ad−bc。三阶沿第一行展开为

    ∣abcdefghi∣=a(ei−fh)−b(di−fg)+c(dh−eg) \begin{aligned} \begin{vmatrix}a&b&c\\d&e&f\\g&h&i\end{vmatrix}\\ &=a(ei-fh)-b(di-fg)\\ &\quad+c(dh-eg) \end{aligned} ​adg​beh​cfi​​​=a(ei−fh)−b(di−fg)+c(dh−eg)​

    三阶也可用对角线法；四阶及以上用展开或消元。

    16.2 nnn 阶行列式的概念 #

    对 nnn 阶方阵 AAA，

    det⁡A=∑σ∈Snsgn⁡(σ)∏i=1nai,σ(i). \det A=\sum_{\sigma\in S_n}\operatorname{sgn}(\sigma)\prod_{i=1}^n a_{i,\sigma(i)}. detA=σ∈Sn​∑​sgn(σ)i=1∏n​ai,σ(i)​.

    σ\sigmaσ 遍历所有列编号的排列，从每行、每列各选一个元素。

    符号由逆序数 N(σ)N(\sigma)N(σ) 决定，为 (−1)N(σ)(-1)^{N(\sigma)}(−1)N(σ)。

    例如排列 (2,1,3)(2,1,3)(2,1,3) 的逆序数为 111，对应项 −a12a21a33-a_{12}a_{21}a_{33}−a12​a21​a33​。

    16.3 行列式的基本性质 #

    转置保持行列式。

    交换两行（列）变号。

    一行乘 kkk，整体乘 kkk。

    某行加另一行的倍数，行列式不变。

    某行可按加法拆成两个行列式，其余行保持相同。

    两行相同导致交换后同时得到原值和相反数，所以值为零。

    倍加性质也由单行线性和相同行为零得出。

    三角矩阵的行列式为对角元的积。

    16.4 按行、按列展开 #

    删去第 iii 行第 jjj 列所得行列式为余子式 MijM_{ij}Mij​，代数余子式 Cij=(−1)i+jMijC_{ij}=(-1)^{i+j}M_{ij}Cij​=(−1)i+jMij​。

    固定行 iii 则 det⁡A=∑jaijCij\det A=\sum_j a_{ij}C_{ij}detA=∑j​aij​Cij​，固定列 jjj 时，按这一列展开。

    det⁡A=∑iaijCij \det A=\sum_i a_{ij}C_{ij} detA=i∑​aij​Cij​

    公式由排列和中按该行选中的列分组得到。

    优先选择零多的行或列。

    16.5 利用行列变换计算行列式 #

    用倍加消元化三角形，尽量避免不必要的缩放。

    若交换 sss 次、对行逐次乘非零系数 k1,…,kmk_1,\ldots,k_mk1​,…,km​，最后 det⁡A=(−1)s∏iuii/∏jkj\det A=(-1)^s\prod_i u_{ii}/\prod_j k_jdetA=(−1)s∏i​uii​/∏j​kj​，其中 uiiu_{ii}uii​ 是最后对角元。

    交换与缩放应写在每一步旁边。

    16.6 特殊行列式的计算技巧 #

    对角与分块三角结构可直接化简。

    若所有行元素和为同一常数 sss，可把各列依次加到第一列，使该列全为 sss，再提取公因子或造零。

    若矩阵的每个非对角元都是 bbb、对角元都是 aaa，这种操作给第一列全为 a+(n−1)ba+(n-1)ba+(n−1)b。

    再将第一行从其余各行减去，可展开得下式。

    det⁡A=(a−b)n−1[a+(n−1)b] \det A=(a-b)^{n-1}[a+(n-1)b] detA=(a−b)n−1[a+(n−1)b]

    其余各行在后 n−1n-1n−1 列只留下对应对角元 a−ba-ba−b。

    典型例题 #

    基础例题。 求下式。

    ∣201030124∣ \begin{vmatrix}2&0&1\\0&3&0\\1&2&4\end{vmatrix} ​201​032​104​​

    第二行只有 333，其符号 (−1)2+2=1(-1)^{2+2}=1(−1)2+2=1，余子式为 8−1=78-1=78−1=7，得 212121。

    进阶例题。 求下式。

    det⁡(0121342710) \det\begin{pmatrix}0&1&2\\1&3&4\\2&7&10\end{pmatrix} det​012​137​2410​​

    交换前两行，变号，得到首行 (1,3,4)(1,3,4)(1,3,4)。

    第三行减两倍首行得 (0,1,2)(0,1,2)(0,1,2)，再减第二行得到零行，所以新行列式为 000，原值也为 000。

    这一过程同时找出了原第三行等于两倍第二行加第一行。

    解题策略与易错点 #

    含许多零时展开，接近三角形时倍加消元。

    矩阵行操作可能改变行列式，应记账。

    单行提出系数 kkk 只乘一次。

    若 nnn 行同时各乘 kkk，行列式乘 knk^nkn。

    巩固练习 #

    1. 计算下式。

      ∣3241∣ \begin{vmatrix}3&2\\4&1\end{vmatrix} ​34​21​​

    2. 计算下式。

      ∣120241012∣ \begin{vmatrix}1&2&0\\2&4&1\\0&1&2\end{vmatrix} ​120​241​012​​

    3. 求三阶矩阵对角元均为 444、其余均为 111 的行列式。

    答案解析 #

    1. 3⋅1−2⋅4=−53\cdot1-2\cdot4=-53⋅1−2⋅4=−5。

    2. 第二行减两倍第一行得 (0,0,1)(0,0,1)(0,0,1)。

      沿第二行展开，符号为 −1-1−1，余子式为 ∣1201∣=1\begin{vmatrix}1&2\\0&1\end{vmatrix}=1​10​21​​=1，所以结果为 −1-1−1。

    3. 各列加到第一列得到常数列 666，再用第一行消去第一列以下的元素，后两行后两列变成对角元 3,33,33,3，故行列式为 545454。
