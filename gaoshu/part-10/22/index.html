    第 22 章 易错知识点专项 #

    第十篇 · 综合解题与考前速查

    专项辨析。每节以常见错误为入口，用反例、条件和正确步骤检验原方法。

    先看懂题，再下笔 #

    订正时可以对每道题做一个最省力的自查：把点代回原式、把积分答案求导、把向量代回方程，或者在区域里挑一个点验证上下限。若验算失败，回到最早的条件或符号，找出第一处变错的地方。

    22.1 定义域与参数取值遗漏 #

    解 ln⁡(x−2)=ln⁡(5−x)\ln(x-2)=\ln(5-x)ln(x−2)=ln(5−x) 前记 2<x<52<x<52<x<5，再比较真数得到 x=7/2x=7/2x=7/2。含参数 aaa 的式子若需除以 aaa，须检查 a=0a=0a=0。例如 ax=aax=aax=a 在 a≠0a\ne0a=0 时 x=1x=1x=1；a=0a=0a=0 时任意实数都满足。

    22.2 极限与连续的误判 #

    点值和附近行为要分开。例如 f(x)=(x2−1)/(x−1)f(x)=(x^2-1)/(x-1)f(x)=(x2−1)/(x−1)（x≠1x\ne1x=1）可在 111 有极限 222，但原式无点值。若补定义 f(1)=3f(1)=3f(1)=3，仍不连续。若左右极限不等，如 ∣x∣/x|x|/x∣x∣/x 在 000，改变点值无法让双侧极限存在。

    22.3 求导时遗漏链式法则 #

    对于 ln⁡(1+x2)\ln(1+x^2)ln(1+x2)，写 u=1+x2u=1+x^2u=1+x2，得 u′/u=2x/(1+x2)u'/u=2x/(1+x^2)u′/u=2x/(1+x2)。如果漏乘 2x2x2x，结果还会破坏原函数为偶函数、导数为奇函数的关系。多元求导时同一目标变量可经多个内层传递，要把各支贡献相加。

    ∫ex dx=ex+C\int e^x\,dx=e^x+C∫exdx=ex+C 表示一族原函数；带上下限的 ∫01ex dx=e−1\int_0^1 e^x\,dx=e-1∫01​exdx=e−1 是数。如果题目给出 F′=fF'=fF′=f 和点值，再用点值确定 CCC。例如 F′=x, F(0)=2F'=x,\ F(0)=2F′=x, F(0)=2 给 F=x2/2+2F=x^2/2+2F=x2/2+2。在断开的定义域上，积分常数可分段独立取值。

    22.5 对数积分遗漏绝对值 #

    在 x≠2x\ne2x=2 的各区间，∫dx/(x−2)=ln⁡∣x−2∣+C\int dx/(x-2)=\ln|x-2|+C∫dx/(x−2)=ln∣x−2∣+C。写 ln⁡(x−2)\ln(x-2)ln(x−2) 会丢失 x<2x<2x<2 的分支。若已知真数为正，比如 x2+1x^2+1x2+1，则可去绝对值。检查方法是对答案求导并验证定义域。

    an→0a_n\to0an​→0 是级数收敛的必要条件，例 ∑1/n\sum 1/n∑1/n 仍发散。比值相邻极限等于 111 时，这一判别不作结论。交错级数不能只看符号交替，要检查幅度趋零并满足最终单调条件，或者另用可证明的判据。

    22.9 矩阵乘法顺序错误 #

    例如 A=(1101)A=\begin{pmatrix}1&1\\0&1\end{pmatrix}A=(10​11​)、B=(2001)B=\begin{pmatrix}2&0\\0&1\end{pmatrix}B=(20​01​)，有 ABABAB 的 (1,2)(1,2)(1,2) 元为 111，BABABA 的为 222。XA=BXA=BXA=B 应在右侧乘 A−1A^{-1}A−1，所以 X=BA−1X=BA^{-1}X=BA−1。转置和乘积求逆都会反转因子顺序。

    22.10 方程组解的情况判断错误 #

    当系数矩阵是方阵且 det⁡A=0\det A=0detA=0，仍需比较秩。例 x+y=2, 2x+2y=cx+y=2,\ 2x+2y=cx+y=2, 2x+2y=c 中，第二行减首行两倍得 0=c−40=c-40=c−4。若 c=4c=4c=4，有无穷多解；否则无解。齐次方程始终至少有零解。

    解题策略与易错点 #
