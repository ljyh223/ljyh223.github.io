    第 12 章 常数项级数 #

    第七篇 · 无穷级数

    官方要求第三部分六（一）。A｜通项必要条件、三个正项判别法、几何、调和及幂次级数；B｜收敛发散、绝对与条件收敛、交错判别和综合判断；C｜级数基本性质。

    先看懂题，再下笔 #

    级数是无穷多个数相加。先看每一项是否趋零，不趋零就能判发散；趋零后再看它像哪类。分式先比最高次幂，带阶乘常用前后项相除，正负交替再检查项的大小是否最终变小到零。每次写下所用判据和理由，避免看到 (−1)n(-1)^n(−1)n 就直接写收敛。

    12.1 无穷级数的基本概念 #

    无穷级数 ∑n=1∞an\sum_{n=1}^\infty a_n∑n=1∞​an​ 由通项 ana_nan​ 构成。它的部分和为 SN=∑n=1NanS_N=\sum_{n=1}^N a_nSN​=∑n=1N​an​。改变有限项只改变有限个贡献，所以敛散性由尾部决定；收敛级数可按有限线性组合运算。

    12.2 级数收敛与发散 #

    若 SNS_NSN​ 趋于有限实数 SSS，级数收敛，和为 SSS。

    若无有限极限则发散，可能趋于无穷或振荡。

    例 ∑n≥1(−1)n−1\sum_{n\ge1}(-1)^{n-1}∑n≥1​(−1)n−1 的部分和在 1,01,01,0 间跳动，因此发散。

    12.3 级数收敛的必要条件 #

    若 SN→SS_N\to SSN​→S，则 aN=SN−SN−1→0a_N=S_N-S_{N-1}\to0aN​=SN​−SN−1​→0。因此通项不趋零可立刻判发散；通项趋零时还要使用判别法。例如 1/n→01/n\to01/n→0，但调和级数发散。

    12.4 几何级数、调和级数与 ppp 级数 #

    几何级数 ∑n=0∞arn\sum_{n=0}^\infty ar^n∑n=0∞​arn（a≠0a\ne0a=0）在 ∣r∣<1|r|<1∣r∣<1 时收敛到 a/(1−r)a/(1-r)a/(1−r)，来自有限和 a(1−rN+1)/(1−r)a(1-r^{N+1})/(1-r)a(1−rN+1)/(1−r)。

    ∣r∣≥1|r|\ge1∣r∣≥1 时通项不趋零。

    ∑n=1∞1/n\sum_{n=1}^\infty1/n∑n=1∞​1/n 发散。

    一般 ppp 级数 ∑n−p\sum n^{-p}∑n−p 在 p>1p>1p>1 收敛，p≤1p\le1p≤1 发散。

    一种说明是把 n=2kn=2^kn=2k 到 2k+1−12^{k+1}-12k+1−1 分组：对 p>0p>0p>0，每组和夹在 2−p2k(1−p)2^{-p}2^{k(1-p)}2−p2k(1−p) 和 2k(1−p)2^{k(1-p)}2k(1−p) 之间，可与几何级数比较。

    p≤0p\le0p≤0 则通项不趋零。

    12.5 正项级数比较判别法 #

    若尾部 0≤an≤bn0\le a_n\le b_n0≤an​≤bn​，∑bn\sum b_n∑bn​ 收敛则 ∑an\sum a_n∑an​ 收敛，∑an\sum a_n∑an​ 发散则 ∑bn\sum b_n∑bn​ 发散。

    理由是部分和递增并受上界控制，或由下界趋无穷。

    若正项 an,bna_n,b_nan​,bn​ 满足 an/bn→L∈(0,∞)a_n/b_n\to L\in(0,\infty)an​/bn​→L∈(0,∞)，则敛散相同，因为尾部可互相用常数倍夹住。

    12.8 交错级数与莱布尼茨判别法 #

    设 bn≥0b_n\ge0bn​≥0，最终单调不增且趋零，则 ∑(−1)n−1bn\sum(-1)^{n-1}b_n∑(−1)n−1bn​ 收敛。原因是偶数部分和向上、奇数部分和向下，且两者之差趋零。若从起始项就满足条件，截断误差不超过下一项 bN+1b_{N+1}bN+1​，因为和夹在相邻两个部分和之间。

    ∑∣an∣\sum|a_n|∑∣an​∣ 收敛称绝对收敛，由 0≤∣an∣±an≤2∣an∣0\le |a_n|\pm a_n\le2|a_n|0≤∣an​∣±an​≤2∣an​∣ 可证明原级数也收敛。原级数收敛而绝对值级数发散称条件收敛。交错调和级数满足交错判别，绝对值为调和级数，因此条件收敛。

    12.10 级数敛散性的综合判断 #

    先查通项，正项再看主导幂、阶乘或 nnn 次方。

    含符号时先判断绝对值级数。

    若发散，再判断原级数。

    若比值或根值等于 111，例如 ∑1/n2\sum1/n^2∑1/n2 与 ∑1/n\sum1/n∑1/n，转回比较。

    结构能裂项时也可直接求部分和，例如 ∑n=1∞1/[n(n+1)]=1\sum_{n=1}^\infty 1/[n(n+1)]=1∑n=1∞​1/[n(n+1)]=1，因为部分和为 1−1/(N+1)1-1/(N+1)1−1/(N+1)。

    典型例题 #

    基础例题。 判断 ∑n=1∞n!/4n\sum_{n=1}^\infty n!/4^n∑n=1∞​n!/4n。比值为 (n+1)/4→∞(n+1)/4\to\infty(n+1)/4→∞，通项从某一项起至少按倍数增长，因此级数发散。

    进阶例题。 判断 ∑n=1∞(−1)n−1n/(n2+1)\sum_{n=1}^\infty(-1)^{n-1}n/(n^2+1)∑n=1∞​(−1)n−1n/(n2+1)。

    绝对值通项与 1/n1/n1/n 之比为 n2/(n2+1)→1n^2/(n^2+1)\to1n2/(n2+1)→1，所以绝对值级数发散。

    x/(x2+1)x/(x^2+1)x/(x2+1) 在 x≥1x\ge1x≥1 递减（导数 (1−x2)/(1+x2)2(1-x^2)/(1+x^2)^2(1−x2)/(1+x2)2），也趋零，故原级数收敛，属于条件收敛。

    解题策略与易错点 #

    先写所用判别法的前提，尤其是非负、单调和趋零。比值计算等于 111 只说明该法无法判断；漏掉绝对值时，不能直接用正项比较判别一个变号级数。

    巩固练习 #

    1. 判断 ∑n=1∞1/(n2+3n)\sum_{n=1}^\infty 1/(n^2+3n)∑n=1∞​1/(n2+3n)。

    2. 判断 ∑n=1∞(−1)n/n2\sum_{n=1}^\infty (-1)^n/n^2∑n=1∞​(−1)n/n2 的收敛类型。

    3. 求下式。

      ∑n=0∞3(−1/2)n \sum_{n=0}^\infty 3(-1/2)^n n=0∑∞​3(−1/2)n

    4. 判断 ∑n=1∞n2/3n\sum_{n=1}^\infty n^2/3^n∑n=1∞​n2/3n。

    答案解析 #

    1. 0<1/(n2+3n)≤1/n20<1/(n^2+3n)\le1/n^20<1/(n2+3n)≤1/n2，比较得收敛。
    2. 绝对值级数是 p=2p=2p=2 的 ppp 级数，故绝对收敛。
    3. 公比 −1/2-1/2−1/2，和为 3/(1+1/2)=23/(1+1/2)=23/(1+1/2)=2。
    4. 相邻比值为 (n+1)2/(3n2)→1/3(n+1)^2/(3n^2)\to1/3(n+1)2/(3n2)→1/3，故收敛。
