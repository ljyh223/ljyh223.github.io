    第 9 章 空间解析几何 #

    第五篇 · 向量代数与空间解析几何

    官方要求第三部分四（二）（三）。B｜平面方程、点到平面距离、空间直线对称式和参数式、位置关系；C｜空间直线一般式及所列空间曲面。

    先看懂题，再下笔 #

    写平面需要“面上的一点＋一个垂直于面的方向”；写直线需要“线上的一点＋沿着线走的方向”。遇到位置关系，先把方向或法向量单独写出来，再代一个点验证。这样可以区分平行异线和重合，也可以区分直线平行于平面和整条直线落在平面里。

    9.1 平面的点法式与一般式方程 #

    过 P0(x0,y0,z0)P_0(x_0,y_0,z_0)P0​(x0​,y0​,z0​) 且法向量为 n=(A,B,C)≠0\mathbf n=(A,B,C)\ne\mathbf0n=(A,B,C)=0 的平面满足

    A(x−x0)+B(y−y0)+C(z−z0)=0. A(x-x_0)+B(y-y_0)+C(z-z_0)=0. A(x−x0​)+B(y−y0​)+C(z−z0​)=0.

    这是 n⋅P0P→=0\mathbf n\cdot\overrightarrow{P_0P}=0n⋅P0​P​=0，展开得一般式 Ax+By+Cz+D=0Ax+By+Cz+D=0Ax+By+Cz+D=0。给三点时取两条不平行边的叉积作为法向量；三点共线时条件不足以唯一确定平面。

    9.2 两平面的位置关系 #

    两法向量不平行时，两平面相交成一直线；点积为零时两平面垂直。法向量平行时再判断某平面上一点是否满足另一方程，成立则重合，否则严格平行。法向量成比例时，也可检查常数项是否成同一比例。

    9.3 点到平面的距离 #

    点 P(x1,y1,z1)P(x_1,y_1,z_1)P(x1​,y1​,z1​) 到平面距离为

    d=∣Ax1+By1+Cz1+D∣A2+B2+C2. d=\frac{|Ax_1+By_1+Cz_1+D|}{\sqrt{A^2+B^2+C^2}}. d=A2+B2+C2​∣Ax1​+By1​+Cz1​+D∣​.

    由任意平面点 P0P_0P0​ 出发向 PPP 的位移在单位法向量上的投影，取绝对值即得垂距。

    9.4 空间直线的方程 #

    过 P0P_0P0​ 且方向向量 s=(l,m,n)≠0\mathbf s=(l,m,n)\ne\mathbf0s=(l,m,n)=0 的参数式为 (x,y,z)=P0+t(l,m,n)(x,y,z)=P_0+t(l,m,n)(x,y,z)=P0​+t(l,m,n)。当三个分量均非零，对称式为 (x−x0)/l=(y−y0)/m=(z−z0)/n(x-x_0)/l=(y-y_0)/m=(z-z_0)/n(x−x0​)/l=(y−y0​)/m=(z−z0​)/n。某分量为零就把对应坐标写为常数。两个相交平面联立给出直线的一般式，方向可取两法向量的叉积。

    9.5 两直线的位置关系 #

    先看两个方向向量。若它们平行，任选两条线上的点 P1,P2P_1,P_2P1​,P2​，检查 P2−P1=λs1P_2-P_1=\lambda\mathbf s_1P2​−P1​=λs1​ 是否有实数解。只要有解就重合，λ\lambdaλ 可以为正、为负或为零；无解则是平行异线。例如沿同一条 xxx 轴从 (1,0,0)(1,0,0)(1,0,0) 指向 (0,0,0)(0,0,0)(0,0,0)，连线指向负向，仍是同一条直线。

    若方向不平行，两条直线各用一个参数，联立三个坐标方程。有共同点就是相交，无共同点就是异面。也可用 P1P2→⋅(s1×s2)=0\overrightarrow{P_1P_2}\cdot(\mathbf s_1\times\mathbf s_2)=0P1​P2​​⋅(s1​×s2​)=0 判断共面。

    9.6 直线与平面的位置关系 #

    将直线 P=P0+tsP=P_0+t\mathbf sP=P0​+ts 代入平面，有常数项加 t(n⋅s)t(\mathbf n\cdot\mathbf s)t(n⋅s)。若点积非零，有唯一交点；此时若 s\mathbf ss 平行于 n\mathbf nn，直线垂直于平面。若点积为零，代入 P0P_0P0​：成立则直线在平面内，否则与平面平行。

    9.7 柱面与旋转曲面 #

    方程 x2+y2=R2x^2+y^2=R^2x2+y2=R2（R>0R>0R>0）不限制 zzz，故是母线平行 zzz 轴的圆柱面。以 zzz 轴为旋转轴，若母线轮廓写为 z=f(r)z=f(r)z=f(r)，旋转后将 rrr 置为 x2+y2\sqrt{x^2+y^2}x2+y2​，得旋转曲面。例如 z=r2z=r^2z=r2 旋转得 z=x2+y2z=x^2+y^2z=x2+y2。只旋转母线的一段时应保留高度或半径限制。

    9.8 球面、椭球面、圆锥面、抛物面 #

    球面为 (x−a)2+(y−b)2+(z−c)2=R2(x-a)^2+(y-b)^2+(z-c)^2=R^2(x−a)2+(y−b)2+(z−c)2=R2，任一点到球心距离为 R>0R>0R>0。中心在原点的椭球面为 x2/a2+y2/b2+z2/c2=1x^2/a^2+y^2/b^2+z^2/c^2=1x2/a2+y2/b2+z2/c2=1（a,b,c>0a,b,c>0a,b,c>0），坐标轴截距为各半轴。x2+y2=k2z2x^2+y^2=k^2z^2x2+y2=k2z2（k>0k>0k>0）是双圆锥面，若只取上半锥还需 z≥0z\ge0z≥0。z=x2/a2+y2/b2z=x^2/a^2+y^2/b^2z=x2/a2+y2/b2 是向上开口的椭圆抛物面；对照水平截面即可辨认形状。

    典型例题 #

    基础例题。 求过 (1,0,2)(1,0,2)(1,0,2)、法向量 (2,−1,3)(2,-1,3)(2,−1,3) 的平面。点法式为 2(x−1)−y+3(z−2)=02(x-1)-y+3(z-2)=02(x−1)−y+3(z−2)=0；展开为 2x−y+3z−8=02x-y+3z-8=02x−y+3z−8=0。原点到平面距离为 8/148/\sqrt{14}8/14​。

    进阶例题。 求直线 (x,y,z)=(1,0,2)+t(1,2,−1)(x,y,z)=(1,0,2)+t(1,2,-1)(x,y,z)=(1,0,2)+t(1,2,−1) 与平面 x+y+z=5x+y+z=5x+y+z=5 的交点并判定是否垂直。代入得到 3+2t=53+2t=53+2t=5，故 t=1t=1t=1、交点 (2,2,1)(2,2,1)(2,2,1)。方向 (1,2,−1)(1,2,-1)(1,2,−1) 与法向量 (1,1,1)(1,1,1)(1,1,1) 不成比例，因此相交而非垂直。

    解题策略与易错点 #

    平面题先找法向量，直线题先找方向向量，再用点积、叉积和代点。空间中的两直线方向不平行时仍要检查能否联立。曲面题用平行于坐标面的截面看形状。

    巩固练习 #

    1. 求过 (0,0,0),(1,0,1),(0,1,1)(0,0,0),(1,0,1),(0,1,1)(0,0,0),(1,0,1),(0,1,1) 的平面。
    2. 判断直线 (t,0,0)(t,0,0)(t,0,0) 与 (0,1,s)(0,1,s)(0,1,s) 的位置关系。
    3. 写出过 (1,0,1)(1,0,1)(1,0,1)、方向 (0,2,−1)(0,2,-1)(0,2,−1) 的直线对称式，并判定与平面 x=1x=1x=1 的关系。

    答案解析 #

    1. 叉积 (−1,−1,1)(-1,-1,1)(−1,−1,1) 是法向量，平面过原点，故 −x−y+z=0-x-y+z=0−x−y+z=0。
    2. 方向 (1,0,0)(1,0,0)(1,0,0) 与 (0,0,1)(0,0,1)(0,0,1) 不平行，且第一条的 yyy 恒为 000，第二条恒为 111，无法相交，故异面。
    3. 由于方向的第一分量为零，写 x=1, y/2=(z−1)/(−1)x=1,\ y/2=(z-1)/(-1)x=1, y/2=(z−1)/(−1)。所有线上点都满足 x=1x=1x=1，直线包含于平面。
