# 四川专升本高等数学完全复习笔记

[查看总目录](#总目录)

适合报考四川省普通高校专升本理工农医类、想从基础自学的读者。全书十篇，从第 0 章到第 23 章，每章一个 Markdown 文件，覆盖微积分、空间向量与解析几何、无穷级数、常微分方程和线性代数。

**2026 年 11 月修订版。** 各章可从“先看懂题，再下笔”开始。先看题目给了什么，再跟着写第一步。想直接练近年形式的大题，可以先看下方的复习入口。

## 怎样使用

1. **打开总目录。** 可以按篇阅读，也可以从下方的专题入口直达相应章节。章末有上一章、下一章和总目录链接。
2. **第一遍练下笔。** 基础薄弱时先做第 0 章。每章从章首的读题提示入手，自己写出第一步，再对照公式和例题。第 4、6、7 章有求导、混合积分和切线接面积的串联练习。
3. **第二遍练独立解题。** 先做章末练习，再逐项核对解析。订正时记录题目条件、错误步骤、正确步骤和验算办法。第 16–19 章集中训练行列式、矩阵、向量组和线性方程组。
4. **最后做综合训练。** 用第 20 章默查公式，第 21、22 章练题型识别与纠错，第 23 章做专项练习和自编模拟卷。按解析定位需要回看的正文。

## 大题复习入口

- **线性方程组。** 从“系数、主元、自由变量”三个词的纸笔含义入手，练三元、四元含参，另练从“有非零解”反推参数。 [第 19 章](part-09/19.md)
- **矩阵综合题。** 练三阶矩阵求逆、右乘型矩阵方程，以及把大整数次幂化成短乘法。 [第 17 章](part-09/17.md)
- **跨章解答题。** 先练从切线接面积、从二重积分接最值、从一阶微分方程接幂级数的第一笔。 [第 21 章](part-10/21.md)
- **近三年题型小结。** 第 23 章第 2 节把 2024–2026 年公开回忆版能核对的大题逐题对应到例题或模拟题，并标出来源和未确认的题面细节。第 6、7 节是 22 题自编模拟卷及逐题解析。 [第 23 章](part-10/23.md)

## 题面术语对应的第一步

| 题面写法 | 草稿上的第一笔 |
|---|---|
| 等价无穷小 | 在乘积或商中，把趋零的因子换成同样快的简单式，如 $\sin(3x)$ 换成 $3x$ |
| 隐函数求导 | 给的是含 $x,y$ 的等式，两边求导；遇到 $y$ 的函数时乘 $y'$ |
| 变限积分 | 对积分整体求导时，先把变化的端点代进被积函数，再乘端点的导数 |
| 凑微分和分部积分 | 先找“内层＋内层导数”；搭不上，再试把乘积分成 $u$ 与 $dv$ |
| 交换二次积分次序 | 画同一块区域，把试切方向旋转九十度，再读新的上下限 |
| 初值与通解 | 先带着任意常数解方程，再用给定点的函数值或导数值定常数 |
| 增广矩阵、主元、自由变量 | 抄系数和右端一起消元；底部找矛盾，各行找领先的非零数，没被主元占住的未知数可自由取值 |

## 掌握层次

| 标记 | 学习目标 | 对应官方术语 |
|---|---|---|
| A｜核心掌握 | 能辨认题型并独立完成标准计算 | 掌握、熟练掌握 |
| B｜基础掌握 | 能解释概念、辨认适用条件并完成基本应用 | 理解、会 |
| C｜了解即可 | 能认出定义或结论，说出基本含义 | 了解 |
| 预备、复习 | 补上先修能力，或回顾已学内容 | 教材内的学习安排 |
| 拓展 | 用于理解推导或增加练习 | 教材内的延伸内容 |

标记按知识点和官方要求的动词归纳。一个小节可能同时含有不同层次，例如广义积分概念为 C，计算方法为 A。例题和模拟题均为教材自编，层次与难度标记用于安排复习。

## 考试范围与来源核验

- 四川省教育厅的考试要求适用于普通高校专升本理工农医类。正文第 1–19 章对应其第三部分的八项内容。第 0 章补代数与三角基础，第 20–23 章负责回顾和训练。官方试卷结构给出线性代数约占 20%，其余约占 80%，这里保留官方的“约”字，书中各章无设定分值。 [四川省教育厅《高等数学》考试要求，官方 PDF](https://edu.sc.gov.cn/scedu/c100495/2021/8/5/0fb9140b78414a36899ae0faf30c30de/files/927cf238daa940d4ba68965c9c4d5028.pdf)
- 四川省教育考试院公布的 2026 年实施规定明确采用自 2024 年启用的考试要求。本书于 2026 年 11 月 16 日核验上述公开文件。用于其他考试年度时，请以当年公告为准。 [四川省教育考试院《2026 年普通高等学校专升本考试招生工作实施规定》](https://www.sceea.cn/Html/202512/Newsdetail_4597.html) · [普通高校专升本公告栏目](https://www.sceea.cn/List/NewsList_15.html)
